
# Student Management System

## Project Overview
A console-based Student Management System developed using Python.
It allows users to manage student records easily.

## Features
- Add Student
- View Students
- Update Student
- Delete Student
- Search Student
- Save student data in JSON file
- Input validation
- Exception handling
- Object-Oriented Programming

## Technologies Used
- Python
- JSON
- VS Code
- Git and GitHub

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python main.py
```
